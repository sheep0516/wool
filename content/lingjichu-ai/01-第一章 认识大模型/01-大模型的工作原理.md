# 大模型是什么：从预测下一个词说起

它的全部工作可以压缩成一句话：读入一段文本，算出「下一个 `token` 最可能是什么」的概率分布，挑一个接上去，再重复。所有看起来像推理、创作、答题的能力，都是这个动作在超大规模参数上的副产品。理解这一点，就能提前判断它在哪会出错。

## 一、最小例子：预测下一个词

假设输入是「今天天气真」。模型不会去查天气数据库，它做的是给词表里每个候选 `token` 打分，再归一化成概率。示意如下（数字只为说明结构，不是真实模型输出）：

| 候选 token | 概率 |
| --- | --- |
| 好 | 0.62 |
| 不错 | 0.11 |
| 热 | 0.09 |
| 冷 | 0.05 |
| 适合 | 0.04 |
| 其他 | 0.09 |

然后按概率抽一个，假设抽到「好」；把「今天天气真好」作为新输入，再预测下一个 `token`。如此循环，直到生成结束符。这叫自回归生成：自己生成的内容会变成下一步的输入。

上下文决定概率分布。如果前文是「今天天气真冷，还下着雨」，候选会整体偏向负面词汇。同一个「真」字后面接什么，完全由前文决定，模型没有独立于上下文的「天气知识」。

想亲手验证，用这个最小请求：

```text
补全下面这句话，只输出 5 个最可能的续写，每个不超过 6 个字，不需要解释：
今天天气真
```

## 二、token 不等于字，也不等于词

模型处理的最小单位是 `token`，它是分词器（`tokenizer`）切出来的片段。英文里一个 `token` 常是半个词或一个词；中文里常见一到两个汉字，也可能是一个词组的片段；数字、标点、代码符号各有切法。

- 一个汉字通常接近 1 个 `token`，但不固定。
- 一个英文单词可能被切成 2–4 个 `token`。
- 空格、换行、标点同样占 `token`。

所以按 `token` 计费而不是按字数：计算量与上下文占用都取决于 `token` 数量，和「几个字」只是大致相关。中文往往比英文更费 `token`，因为同义内容用汉字写得紧凑，但分词粒度未必划算。按当前主流工具，中文大约每个汉字 1 个 `token` 上下，具体取决于分词器版本。

## 三、输出是概率分布，采样决定具体答案

模型给出的不是「唯一答案」，而是整个词表上的概率分布。最终选哪个词，由采样策略决定：

- 贪心：永远选概率最高的。稳定，但容易重复、呆板。
- 温度（`temperature`）：调高让低概率词更有机会被选中，输出更发散；调低更保守。
- `top-p` / `top-k`：只在概率最高的一小部分候选里抽，砍掉长尾。

这就是同一个问题问两次得到不同答案的原因。不是模型「改变主意」，而是采样本来就有随机性。要稳定就调低，要多角度候选就调高。

## 四、参数是统计规律，不是数据库

模型里的参数（权重）是训练时从海量文本里学到的数值。它们编码的是「词与词、概念与概念如何共现」的统计规律，而不是一条条可检索的记录。

| 对比项 | 数据库 | 大模型参数 |
| --- | --- | --- |
| 存什么 | 具体记录、字段 | 数值化的关联强度 |
| 怎么取 | 精确查询 | 前向计算后近似浮现 |
| 能否逐条修改 | 可以 | 很难定点修改 |
| 冷门事实 | 有就有，没有就没有 | 可能记混或编造 |
| 更新方式 | 增删改 | 重新训练或外挂检索 |

所以「模型知道某公司某年的营收」要谨慎看待：它可能只是训练文本里反复出现的高概率关联，也可能根本没有，只是拼出了一个像样的数字。

## 五、「理解」的实质是压缩后的模式匹配

训练目标是把下一个 `token` 预测得更准，为此它必须压缩语言里的语法、事实关联和常见推理套路。所谓「理解」，是在这套压缩表示上做模式匹配，而不是拥有和人一样的感觉与经验。

这个说法有边界：它解释了模型为何会犯看似低级的错误（匹配到表面相似的句式），但解释不了它为何在规模变大后表现出跨任务通用性，后者目前没有公认的完整解释，别把比喻当原理。

## 六、和搜索引擎、规则程序的区别

| 对比项 | 搜索引擎 | 规则程序 | 大模型 |
| --- | --- | --- | --- |
| 输出 | 已有网页的链接 | 按 `if-else` 确定 | 生成的新文本 |
| 依据 | 索引与排序 | 明确写死的逻辑 | 参数中的统计规律 |
| 事实来源 | 实时抓取 | 代码里的分支 | 训练数据，可能过时 |
| 出错怎么查 | 点开原文核对 | 打断点、看分支 | 很难定位到「哪条知识」 |
| 适合 | 找资料 | 确定性流程 | 语言类、开放式任务 |

三者不是替代关系：查事实用搜索，跑流程用代码，写作与归纳用模型，是最稳的组合。

## 速查

- 大模型的唯一动作：给定前文，预测下一个 `token`。
- 自回归：自己生成的内容会作为下一步输入。
- `token` 是分词器切出的片段，不等于字或词；计费按 `token`。
- 输出是概率分布，采样策略决定具体词；温度高更发散。
- 参数是统计规律，不是可逐条检索的数据库。
- 「理解」是压缩表示上的模式匹配，不是人的经验。
- 事实要外部核对，确定性流程交给代码。
- 同一问题答案不同是采样的正常现象，不是模型坏了。
