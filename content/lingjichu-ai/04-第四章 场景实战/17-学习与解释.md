# 学习与解释：把概念讲到能复述

检验是否学会一个概念，标准不是「看着眼熟」，而是能用自己的话讲清楚、举出例子、答出追问。AI 在这件事上最有用的地方，不是替你解释，而是逼你暴露漏洞。

## 一、费曼式循环

费曼式循环分三步，每步交给不同角色：

1. 自己解释：不看资料，用大白话把概念讲一遍。讲不清的地方就是漏洞。
2. 让模型找漏洞：把解释发给模型，要求它指出含糊、跳跃、错误之处，而不是夸你。
3. 再简化：带着批评重讲一遍，目标更短、更准、没有行话。

循环一到两轮就够。第二轮后还讲不清，多半是前置概念缺了，回去补基础，而不是继续堆话术。复述时尽量不用原文的词，逼自己换说法。一旦只能照念，说明理解还停在记忆层，不在理解层。

## 二、出题与批改：检验掌握程度

「我懂了」最不可靠。让模型出题并批改，能把感觉变成证据：

- 按难度出题：概念题、应用题、易错题各若干。
- 先自己作答，再让模型逐题批改并说明错因。
- 错题不立刻看答案，先自己重做一遍，再看解析。

关键在顺序：先答后看。否则只是在读答案，不是在做题。批改后把错题按类型归类：概念混淆、边界不清、计算失误。同类错误出现两次以上，说明那块基础要重学。

## 三、类比与追问：借用直觉，控制深度

| 类比的作用 | 类比的失效 |
| --- | --- |
| 把抽象概念接到已知经验上 | 类比只近似，不精确 |
| 帮助记住结构 | 边界条件常被忽略 |
| 提供第一直觉 | 越界后结论会错 |

好类比能把你带进门，坏类比会让你带着错误直觉走很远。用法是：先用类比建立直觉，再明确问「这个类比在哪里不成立」，把边界标出来。

连续追问「为什么」能挖到根因，但会失控，需要设定深度与终点：

- 限定层数：最多三层，第三层必须落到可验证的机制或定义。
- 每层换角度：一层问因果，一层问前提，一层问反例。
- 到定义层就停：再往下是哲学问题，不是学习目标。

追问到第三层若出现两个都合理的答案，说明这里本身有争议，记下来，别急着定论。

## 四、从零散概念到概念地图

零散记住的名词很快会忘。整理成概念地图，记忆才成网：

- 列出所有相关概念，每个配一句话定义。
- 标关系：哪些是上位、下位，哪些是因果，哪些并列。
- 找枢纽：被最多概念连接的那个，往往最该先吃透。

可以让模型帮你起草关系，但关系是否成立，要你自己判断。画完后做一次口头讲解，沿着连线从枢纽概念讲到叶子概念，卡住的地方就是地图缺的边。

## 五、避免「看懂了」的错觉

四种自测缺一不可：

- 复述：合上资料，用自己的话讲一遍。
- 举例：举一个正例和一个反例。
- 自测：做几道没见过的题。
- 找反例：构造一个让结论失效的情形。

能复述、能举例、能做题、能构造反例，才算真的掌握。自测时给自己限定时间，比如每道题 2 分钟。想太久说明还没形成条件反射，需要再练。

## 六、30 分钟学习流程与两段提示词

流程不必严格卡时间，顺序比时长重要：先暴露漏洞，再补，再用题目验证。

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 0–5 分钟 | 读原始材料，标出不懂的词 | 疑问清单 |
| 5–10 分钟 | 让模型解释疑问，要求给例子 | 初步理解 |
| 10–18 分钟 | 自己复述，让模型找漏洞 | 修正后的解释 |
| 18–25 分钟 | 让模型出题，自己作答并批改 | 错题与错因 |
| 25–30 分钟 | 画概念地图，标边界与反例 | 一页笔记 |

两段可复制的提示词：

```text
我要学习【概念】。请先不要解释，而是向我提 3 个由浅入深的问题，帮我暴露理解盲区。
等我回答后，指出我哪里含糊或错误，再给出准确解释，并附一个正例和一个反例。
不要使用行话；如果必须用术语，先用一句话定义它。
```

```text
请围绕【概念】出 6 道题：2 道概念题、2 道应用题、2 道易错题。
我作答后，请逐题批改，说明错因，并指出我可能存在的共同误区。
在我提交答案前，不要给出任何提示或答案。
```

## 检查清单

- [ ] 能不看资料用自己的话讲清概念
- [ ] 讲完后让模型找过漏洞，并重讲了一遍
- [ ] 做过题，且是先答后看解析
- [ ] 能举出正例与反例
- [ ] 类比已标明失效边界
- [ ] 「为什么」追问控制在三层内
- [ ] 概念地图画出了上下位、因果与枢纽
- [ ] 留有一条可复习的一页笔记
