# 结构化提示词：模板与复用

值得反复用的提示词，应该固化成模板：结构固定、变量留空、验证过再存。模板的价值不是「一次写得更长」，而是把有效的约束固定下来，下次只换材料，不重新试错。

## 一、六格模板

角色、任务、背景、约束、输出格式、示例。每一格的填写要点如下。

| 格子 | 作用 | 填写要点 |
| --- | --- | --- |
| 角色 | 定视角和用词 | 一个具体身份，不超过一句 |
| 任务 | 定动作 | 单一动词，说清产物是什么 |
| 背景 | 补上下文 | 读者、场景、已有材料 |
| 约束 | 定边界 | 三到五条，可验证 |
| 输出格式 | 定形状 | 字段、顺序、长度 |
| 示例 | 定风格 | 一条，短，同类型 |

角色容易被写虚。「你是一位资深专家」几乎没有信息量，「你是一名负责校招简历筛选的工程师」才定住了视角。示例可以省略，其余五格建议都填。

示例这一格最容易写废：贴一整段长范文，模型会照抄措辞；只写「参考上面的风格」，又等于没给。合适的做法是截取两三句最能代表目标语气的样本，并在旁边注明「要的是这种句式，不是这些内容」。

## 二、三个成品模板

变量统一用〔方括号〕标出，复制后替换即可。

**写作改写类**

```text
你是〔公众号/简历/周报〕的写作者。
任务：把下面的原始材料改写成〔一段说明/三条要点/一条摘要〕。
背景：读者是〔读者身份〕，他们已经知道〔已知信息〕，关心的是〔关注点〕。
约束：
- 全文不超过〔字数〕字
- 只使用材料里的事实，不补充材料里没有的数字
- 不使用〔禁用词列表〕
输出格式：〔段落/条目/表格〕，〔具体结构说明〕。
示例：（可选，贴一条与目标风格一致的短样本）
原始材料：
〔粘贴材料〕
```

**学习解释类**

```text
你是〔领域〕的讲解者，面向〔零基础/有编程经验/跨专业〕的读者。
任务：解释〔概念/代码/论文段落〕，让读者能用自己的话复述。
背景：读者已经掌握〔前置知识〕，卡在〔具体疑问〕。
约束：
- 先用一句话给结论，再展开
- 至少给一个日常类比，并说明类比在哪里不成立
- 不引入未解释的术语
输出格式：四个小段，依次为「一句话结论」「为什么」「类比与边界」「一个例子」。
需要解释的内容：
〔粘贴内容〕
```

**信息整理类**

```text
你是信息整理助手。
任务：从下面的材料中抽取〔字段清单〕，整理成表格。
背景：材料是〔来源类型〕，用于〔用途〕。
约束：
- 只使用材料中出现的信息
- 材料中没有的字段填「未提及」，不要推测
- 同一对象的多条信息合并为一行
输出格式：Markdown 表格，列为〔列名 1、列名 2、列名 3〕，顺序固定。
材料：
〔粘贴材料〕
```

## 三、变量标注与存放

- 变量统一用〔方括号〕，一眼能看出哪里要换。不要用 `{}` 或 `<>`，容易和正文符号混淆。
- 命名用「场景-对象-版本」：`周报-后端实习-v2`、`论文摘要-抽取-v1`。场景在前，找的时候按场景翻。
- 存放位置固定，一个文件夹或一个笔记页，按场景分。模板散在聊天记录里等于没有。
- 版本号只在实质改动时加：改了约束或格式算一次，换个变量值不算。

## 四、模板失效时的排查

模板用久了会「失灵」，多数是某一处被悄悄改坏了。按现象定位：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 结构不稳，有时表格有时段落 | 输出格式描述不完整 | 补上列名、顺序、条目数量 |
| 内容变空，全是套话 | 背景被删或材料没贴全 | 补回读者、场景和原始材料 |
| 语气不对 | 角色或示例被换掉 | 换回验证过的角色描述，补一条示例 |
| 出现禁用词 | 约束被合并或删减 | 恢复禁用词清单，逐条列明 |

排查顺序从下往上：先看材料有没有贴全，再看格式，最后看角色。很多时候不是模板坏了，是这次忘了贴材料。

## 五、只存验证过的版本

- 一个模板先在两三个真实任务上跑通，再存。一次成功可能只是运气。
- 每次失效都记一行：什么任务、哪一格出问题、怎么改的。这份记录比模板本身更值钱。
- 禁止项放在约束里性价比最高。「不要写计划」「不要用感叹号」「不要编数字」，一条禁止项能挡掉一类返工，比十句「请写得专业」有用。
- 模板别追求通用。一个模板覆盖太多场景，最后每一格都要重写，不如拆成两个专用模板。
- 模板要备份。本地文档、云笔记都行，重点是能搜到、能对比历史版本；只存在某个聊天窗口里，换设备或清空记录就没了。

## 速查

- 六格：角色、任务、背景、约束、输出格式、示例。
- 角色写具体身份，不写「资深专家」。
- 变量用〔方括号〕，命名「场景-对象-版本」。
- 模板集中存放，散在聊天记录里等于没有。
- 失效先查材料，再查格式，最后查角色。
- 跑通两三个真实任务再存。
- 禁止项一条顶十句形容词。
