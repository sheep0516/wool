# Agent：多步骤任务的拆解与验收

Agent 不是更聪明的模型，而是一个循环：看当前状态、选工具、拿结果、再决定下一步，直到满足停止条件。它的价值在把多步任务串起来，风险也在同一处——每一轮都可能偏离目标，或把上一轮的错误放大。

## 一、Agent 的五个组成部分

- 模型：负责决策与生成，决定下一步做什么。
- 工具：可改变状态的操作集合，如读写文件、调用接口。
- 循环：反复执行「观察、决策、行动」。
- 停止条件：达成目标、步数上限、超时、连续失败。
- 记忆：保存中间结果与已做动作，避免重复劳动。

缺任何一项都会出问题：没有停止条件会死循环，没有记忆会反复做同一步，没有工具就退化成普通对话。

## 二、什么任务适合交给 Agent

适合的任务通常同时满足几条：步骤多，单次提示词难以完成；中间结果可验证，每步有明确对错；失败可回滚，或至少不产生不可逆后果；输入输出结构化，便于检查。

反例也很清楚：一次性就要判断正确的任务、后果不可逆的操作、验收标准说不清的任务，都不适合。把这类任务硬塞给 Agent，只会把不确定性放大成事故。

判断时可以用一个反问：如果中途出错，能否停下来只重跑一步？不能的话，先改造流程，再考虑交给 Agent。

## 三、任务拆解：目标、子任务、检查点

先写清可验收的最终状态，再倒推步骤。每个子任务定义三件事：输入是什么、输出是什么、怎么算完成。检查点是可自动或人工确认的中间状态，例如「文件已生成且行数大于 0」「三节内容都不为空」。

拆解粒度的经验：一步只做一件事，且一步的结果能被独立检查。步子太粗，出错难定位；太细，调用次数与成本飙升。

## 四、失败模式与防护

| 失败模式 | 典型表现 | 防护手段 |
| --- | --- | --- |
| 死循环 | 同一工具被反复调用 | 步数上限、重复动作检测 |
| 目标漂移 | 做着做着偏离原目标 | 每步回读目标、检查点校验 |
| 越权操作 | 调用了不该调的工具 | 最小权限、高危操作拦截 |
| 成本失控 | token 与调用数暴涨 | 预算上限、按步监控用量 |
| 错误累积 | 早期错误被后续步骤放大 | 关键步骤人审、保留可回滚状态 |

这五类里，错误累积最隐蔽。单步看起来都对，结果却全错，事后很难定位。对策是把关键中间结果落盘，让每一步都能单独复现与回退。

## 五、沙箱、最小权限与人审节点

沙箱指在隔离环境运行：限制可访问的目录、禁止任意网络请求、用临时副本而非原文件。最小权限指只给完成任务必需的读写范围，例如只读某个输入目录。

必须设人审节点的场景：不可逆操作（删除、覆盖）、对外发送（邮件、消息、提交）、花钱、改动生产数据。人审不是加一道弹窗，而是让人看到将要执行的具体内容再点确认。

沙箱与最小权限都要在程序侧实现，写进提示词不算。模型说「我只读」不代表它真的只读，权限由运行环境约束。

## 六、流程示例与不该交给 Agent 的任务

一个整理文件并生成周报的流程可以这样设计：

| 步骤 | 动作 | 工具 | 检查点 | 人审 |
| --- | --- | --- | --- | --- |
| 1 | 收集本周提交与笔记 | 读文件 | 文件数大于 0 | 否 |
| 2 | 归并成草稿 | 模型 | 每个来源都有对应内容 | 否 |
| 3 | 生成周报 | 模型 | 三节结构完整 | 是 |
| 4 | 存档到指定目录 | 写文件 | 路径与命名正确 | 是 |

对应的任务描述要把验收标准写进去，而不只是说「帮我整理」：

```text
任务：把 inbox 目录下的 Markdown 整理成一篇周报草稿。
目标状态：生成 weekly-YYYY-WW.md，含「本周完成、进行中、阻塞」三节。
约束：只读 inbox，不修改原文件；不发起任何外部请求。
检查点：每个来源文件至少有一条对应内容，无内容时写「无」。
停止条件：草稿生成并保存，或步数超过 10。
验收：人工阅读后确认；不合格则回退草稿重跑，不覆盖原文件。
```

明确不该交给 Agent 的任务：不可逆的高风险决策、验收标准无法量化的任务、需要在瞬间判断法律或伦理边界的任务、数据敏感且无法隔离运行环境的任务。这些任务即便能自动化，也应保留人工主导。

上线前先小范围试跑：用历史数据跑几遍，比对人工结果，确认稳定后再接真实目录。

## 检查清单

- [ ] 任务是否有明确的最终状态与验收标准
- [ ] 是否设了步数上限、超时与连续失败停止条件
- [ ] 每个子任务是否有可检查的输入输出
- [ ] 关键中间结果是否落盘以便回滚
- [ ] 是否在沙箱与最小权限下运行
- [ ] 不可逆操作与对外发送是否有人审
- [ ] 是否设了成本与调用次数预算
- [ ] 这类任务是否本来就不该交给 Agent
