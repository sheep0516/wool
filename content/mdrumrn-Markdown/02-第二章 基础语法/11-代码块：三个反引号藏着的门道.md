# 代码块：三个反引号藏着的门道

> Markdown语言入门 合集 · 第二章 · 基础语法 · 第 11 篇

> 推荐阅读时间：约 7 分钟

> 它不只是给程序员用的

很多人一看到"代码块"三个字，第一反应是：这跟我没关系。

刚好相反。

**在你和 AI 打交道的日常里，代码块是除了标题之外，你最该先学会的一个符号。** 因为你从 AI 那儿拿到的报错、指令、提示词，几乎都要靠它才能原样落地。

## 先说清它和行内代码的区别

第 7 篇讲过**行内代码**：夹在句子中间，包住几个字，比如 `练习.md`。

代码块是它的整段版本——**一整块**，而不是一处几个字。

## 怎么写：上下各三个反引号，独占一行

```text
这里是代码块里的内容
```

要点有三个：

- 上面三个、下面三个，**各自占一整行**，不能跟文字挤在一起。
- 上下必须成对，少了下面那一组，后面所有内容都会被吞进去。
- 中间的内容会**原样保留**：换行、空格、空格的数量，都不会被 Markdown 改动。

最后这一点，才是它真正的价值。



## 开头那一行可以标语言

在开头那三个反引号后面写一个语言名，它会自动上色，也就是高亮：

````markdown
```python
print("hello")
```
````

常用的有 `python`、`javascript`、`bash`、`text`。不知道写什么就写 `text`，一样能用，只是不上色。

## 五个非代码用途（这一篇的重点）

这才是我最想让你记住的部分。

- **一、贴报错信息。** AI 或软件给你的报错，往往十几行、带缩进。直接粘贴会被自动排版搞得乱七八糟；包进代码块，它长什么样就是什么样，谁来都能看懂。
- **二、存 AI 提示词。** 把自己反复要用的那段提示词存成一块，需要的时候复制就走，也不用担心里面的符号被吞掉。
- **三、做纯文本表格。** 有些平台不认表格语法，用代码块手动对齐也能排出整齐的栏，粘到哪儿都不会散。
- **四、画文件目录树。** 想展示一个文件夹里有什么，代码块是唯一不会让对齐跑偏的写法：

```text
练习文件夹/
├── 练习.md
└── 图片/
```

* **五、给朋友的备忘。** 一串地址、一个账号、一段歌词，包进代码块发出去，就不会被平台自动加上乱七八糟的格式。

**一句话：凡是"要被原样复制走"的内容，都该放进代码块。**

## 反引号在键盘哪儿

它在键盘**左上角**，Esc 键的下面、数字 `1` 的左边，和波浪号在同一个键上。

新手的坑在这儿：**中文输入法下敲出来的是全角的，不生效。** 所以敲之前先切英文输入法。

这也和第 5、6、7 篇那几个坑是同一个道理：凡是不生效，先怀疑输入法。

## 顺手收一张：第二章符号速查表

第二章到这里，一个符号一个符号地过完了。把它们压成一张表：

| 符号      | 这么敲               | 会长成什么         |
| :-------- | :------------------- | :----------------- |
| `#`       | `# 标题`             | 一级标题           |
| `**`      | `**重点**`           | 加粗               |
| `*`       | `*强调*`             | 斜体               |
| `~~`      | `~~作废~~`           | 删除线             |
| `` ` ``   | `` `文件名` ``       | 行内代码           |
| `-`       | `- 一条`             | 无序列表           |
| `1.`      | `1. 第一步`          | 有序列表           |
| `- [ ]`   | `- [ ] 待办`         | 待办清单           |
| `>`       | `> 引用别人的话`     | 引用块             |
| `---`     | 单独一行             | 分隔线（建议少用） |
| `[ ]( )`  | `[文字](网址)`       | 超链接             |
| `![ ]( )` | `![说明](图片)`      | 图片               |
| ` ``` `   | 上下各三个，独占一行 | 代码块             |

这一张，建议你截图存下来，或者干脆照着敲一遍——**敲一遍比看十遍记得牢。**

## 5 分钟动手

找一段你平时最常用的 AI 提示词（哪怕只有两行也行），用代码块包起来。

包好之后，把整块内容复制出去，粘贴到别的地方看看：格式还在吗？如果还在，你就掌握了它最大的用处。

## 本章总结

第二章七篇，讲的全是"怎么写对"。回头看一眼你走过的路：

* **先搭骨架。** `#` 的个数就是层级，后面空一格，一篇文章只用一个一级标题。
* **再管分段。** 在源码模式，想换段就空一行；在预览模式，回车就是换段，Shift + 回车是段内换行。
* **再分轻重。** 加粗、斜体、删除线、行内代码管"哪句重要"，但一篇里加粗别超过 3–5 处。
* **再排并列。** 并列用列表，叙事用段落；序号不用自己写，嵌套缩进两个空格。
* **最后往外接。** 引用块圈出别人的话，链接和图片引用外面的东西，代码块保住"要原样复制"的内容。

到这里，你已经能把一篇文章完整写出来了。**从下一篇开始，我们换一个问题：怎么把它写得好看。**
