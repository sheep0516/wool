# 图片：路径、替代文字与排版

`![替代文字](路径)` 是图片的标准语法，比链接只多一个感叹号。路径以当前 Markdown 文件所在目录为基准；替代文字不是可选项，它在图片加载失败和无障碍阅读场景下是唯一的说明。

## 一、基本语法与替代文字

感叹号、方括号、圆括号三段紧挨着，中间不能插入空格。

````markdown
![登录界面截图](assets/login.png)
![登录界面截图](assets/login.png "登录页")
````

替代文字（alt）有三个实际作用：图片加载失败时浏览器显示这段文字；屏幕阅读器朗读它；搜索引擎把它当作图片语义。写成「图 1」没有信息量，应写成「登录页输入框与验证码区域」。圆括号里的 title 与链接的 title 行为一致，悬停显示，移动端无效，不要用它承载必要信息。

## 二、路径与 assets 目录

路径规则和链接完全一样，相对当前文件。推荐在每章目录下建一个 `assets` 或 `images` 子目录，按章节存放，避免所有图片堆在仓库根目录。

| 场景 | 写法 |
| --- | --- |
| 同级 assets 目录 | `assets/login.png` |
| 上级目录的共享图片 | `../assets/logo.png` |
| 子目录图片 | `images/2026/login.png` |

常见组织方式有两种：每章一个 `assets`，图片跟着章节走，移动章节时不会断链；仓库根目录一个 `assets`，图片集中管理，但路径里会出现多个 `../`。个人知识库建议用前者，理由是一章的内容连同图片可以整体搬走，不用回头改路径。

图片文件名也值得定规矩：全部小写、用连字符代替空格、避免中文与括号，例如 `2026-11-login-flow.png`。这样链接里不会出现需要编码的字符，也不会因为大小写问题在服务器上断掉。截图工具默认生成的 `image-20261123-1.png` 虽然能用，但时间一长完全看不出内容，检索时只能逐张点开。

## 三、尺寸控制的平台差异

标准 Markdown 没有尺寸语法。想改大小只有三条路，全部属于扩展：

- 内嵌 HTML：`<img src="assets/login.png" width="480" alt="登录界面">`，GitHub、Typora、浏览器预览都支持，但纯 Markdown 渲染器可能直接输出源码。
- 工具私有语法：Obsidian 用 `![[login.png|480]]` 指定宽度；Typora 调整图片大小时会把该行改写成带 `zoom` 样式的 `<img>` 标签，换工具即失效。
- 不改尺寸，用图片编辑软件预先裁好。

跨平台分发的笔记不建议依赖私有语法，优先在源文件里控制像素尺寸，这样任何渲染器看到的效果都一致。另外，同一张图在不同渲染器里的默认缩放行为也不同：网页里通常按原始像素显示，移动端会被屏幕宽度压窄。写死 `width` 反而可能在窄屏上溢出，需要配合 `max-width: 100%`，这已经超出 Markdown 能表达的范围。

## 四、图注与可点击图片

图注没有标准语法。常见做法是在图片下方单独一行写斜体或普通文字，靠排版暗示这是说明：

````markdown
![登录页](assets/login.png)

*图 1　登录页的验证码区域*
````

需要图片可点击跳转大图或外部页面时，把图片语法整个放进链接的方括号里：

````markdown
[![登录页缩略图](assets/login-small.png)](assets/login.png)
````

外层是链接，内层是图片，外层圆括号里是点击后打开的目标。层级写反，结果就是一张带链接样式的图，而不是可点击的图。

## 五、常见错误

| 错误写法 | 问题 |
| --- | --- |
| `![图](Assets/Login.png)` | 路径大小写与实际文件不符 |
| `![图](assets/my pic.png)` | 空格未编码，应写 `my%20pic.png` |
| `![图](C:\Users\me\pic.png)` | 本机绝对路径，换机即失效 |
| `![图](../03-第三章/pic.png)` | 图片放在别的章节目录，移动后断链 |
| `[图](assets/login.png)` | 少了感叹号，渲染成链接而非图片 |

Windows 本地不区分大小写，容易掩盖问题；一旦推到 GitHub 或部署到 Linux 服务器，大小写不一致的图片会直接返回 404。另一类隐性问题是只复制图片而没有移动，源文件被删后链接失效；整理图片目录时应当整体移动 `assets` 文件夹，而不是逐张拖拽。

## 速查

- 语法：`![替代文字](路径)`，感叹号不能省。
- 路径相对当前文件所在目录。
- 每章一个 `assets` 目录，图片跟随章节移动。
- 替代文字写清图片内容，不写「图 1」。
- 标准语法不支持尺寸，HTML `width` 或工具私有语法都是扩展。
- 图注用图片下方一行文字模拟，无标准写法。
- 可点击图片：`[![alt](小图)](大图)`。
- 路径大小写、空格编码、绝对路径是最常见的三类断链原因。
