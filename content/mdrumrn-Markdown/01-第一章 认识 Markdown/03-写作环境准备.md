# 写作环境准备

建一个 UTF-8 编码的 `.md` 文件，用带实时预览的编辑器打开，配好自动保存、大纲和图片相对路径，就能开始写。工具选哪一类，取决于你想要「所见即所得」还是「文件即一切」。

## 一、文件本身的要求

- 扩展名用 `.md`。`.markdown` 多数工具也认，但统一成 `.md` 最省事。
- 编码用 UTF-8，不要带 BOM。带 BOM 时，部分工具会把文件开头的标记当成正文，导致首行多出一个怪字符，或让开头的元数据失效。
- 换行符 LF 或 CRLF 都能正常渲染。Windows 默认 CRLF，macOS 和 Linux 默认 LF，同一仓库混用会产生整文件差异。
- 保存为纯文本，不要用 `.rtf` 或 `.docx` 冒充。
- 文件名避开特殊字符。`#`、`?`、`%` 在链接里需要转义，中文名在个别工具里也可能显示异常。

这几项都不涉及内容，却是最容易出问题的地方，先确认再动笔。

## 二、三类工具怎么选

| 工具 | 形态 | 适合谁 | 注意点 |
| --- | --- | --- | --- |
| Typora | 桌面客户端，所见即所得 | 想专注写作、不想盯着符号的人 | 付费软件，导出格式多 |
| VS Code 加预览插件 | 代码编辑器 | 已经在写代码、需要 Git 集成的人 | 内置预览快捷键 `Ctrl+Shift+V`，插件可补目录生成和快捷键 |
| Obsidian | 本地仓库式笔记 | 要建知识库、靠双链组织笔记的人 | 免费用于个人，文件就是本地 `.md`，扩展语法较多 |

三者都只读写 `.md`，换工具不需要迁移内容。写单篇文章，Typora 最省心；和代码、Git 放一起，VS Code 最顺手；长期积累成知识库，Obsidian 更合适。Typora 可在偏好设置里把插入的图片复制到指定文件夹；Obsidian 可在设置里指定附件目录，两者都建议落在仓库内部。

## 三、最小配置清单

- 自动保存：开启，避免预览和内容对不上。VS Code 里把 `files.autoSave` 设为 `afterDelay`。
- 实时预览：编辑区与预览区并排，或直接所见即所得。
- 大纲：能按标题跳转，长文必备。VS Code 用左侧大纲视图，Typora 用侧边栏大纲。
- 图片粘贴：配置粘贴后自动存到相对目录，例如 `assets/`，不要落到绝对路径。
- 字体与行高：正文用中文正文字体，代码用等宽字体，行高放到 1.6 以上更耐读。
- 同步与备份：把笔记目录放进 Git 或网盘，误删可以恢复。

这六项配好，写普通笔记和长文都不会再被环境打断。

## 四、目录与文件组织

- 一个主题一个文件，文件名用「序号-标题」，排序即阅读顺序。
- 章节用目录承载，目录里只放文件和子目录，不写正文。
- 图片统一放同级的 `assets/` 目录，引用写相对路径。
- 文件名不用空格，用短横线连接，省掉链接和命令行里的转义麻烦。

目录示例：

```text
Markdown入门/
├── 01-认识 Markdown/
│   ├── 01-是什么.md
│   └── assets/
│       └── 结构示意图.png
└── 02-语法/
    └── 01-标题.md
```

每个子目录可以放一个 `README.md` 作索引，列出该章的文件与阅读顺序，索引本身不写正文。

一个可直接复制的最小正文片段，标题和各节标题按需补上：

```markdown
一句话结论写在这里。

- 要点一
- 要点二

> 边界情况：仅适用于 Python 3.10 及以上。

示例命令：`git status`
```

## 五、从零开始的第一步

1. 在目标目录新建文件，命名为 `test.md`，扩展名要手动改成 `.md`。
2. 用编辑器打开，第一行写 `# 测试标题`，空一行，再写两段正文。
3. 打开预览，确认标题变大、段落分开、行内代码有底色。
4. 查看编码，确认为 UTF-8。VS Code 右下角状态栏会显示编码和换行符。
5. 保存、关闭、重新打开，内容完整即说明环境可用。

如果预览里出现乱码或原始符号，先回头检查编码和空格这两项，多数问题出在这里。

判断环境是否正常，看三点：符号被解释成结构，中文没有乱码，图片能正常显示。三点都满足就可以开始正式写作，不必再折腾插件。

## 六、常见坑

- 用记事本保存成 `.txt`：能打开但没有预览效果，实际文件名是 `test.md.txt`，因为系统隐藏了已知扩展名。
- 编码变成 GBK：旧版记事本默认 ANSI，中文换到别的工具就变乱码。另存为时显式选 UTF-8。
- 图片用绝对路径：`C:\Users\...\a.png` 换台机器就失效，应改成相对路径。
- 换行符混用：同一仓库里 CRLF 与 LF 混在一起，diff 会显示整个文件被改动。
- 符号后少空格：`#标题` 不生效，必须是 `# 标题`；列表符号后同样要空格。
- 标点混用：中文句子里用全角标点，英文和数字两侧留空格，排版才不挤。
- 同步冲突：两台设备同时改同一文件，网盘会生成「副本」文件，需要手工合并。
- 插件差异：不同预览插件对表格、脚注、数学公式的支持不同，换插件前先确认关键语法能渲染。

## 速查

- 扩展名 `.md`，编码 UTF-8，不带 BOM。
- 标题符号后必须有空格：`# 标题`。
- Typora 重写作，VS Code 重工程，Obsidian 重知识库。
- 必配：自动保存、实时预览、大纲、图片相对路径。
- 一个主题一个文件，图片放 `assets/`。
- 记事本默认存 `.txt`，改扩展名要确认没被隐藏。
- 乱码先查编码，图片失效先查路径。
