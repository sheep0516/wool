# 常见问题排查手册

结论：Markdown 的显示问题九成来自三处——空行不足、缩进被误读、符号未转义。按这个顺序排查，再考虑渲染器差异；能用改内容解决的，就不要换工具。

## 一、通用排查顺序

1. 补空行：块级元素前后各留一个空行。
2. 查缩进：行首误加 4 个空格会被当成代码块，列表续行要对齐。
3. 查转义：`*`、`_`、`#`、`|`、`<` 出现在正文里时用反斜杠转义。
4. 对照预览：同一份内容在两个渲染器里打开，差异处就是语法歧义点。
5. 换工具验证：换一个编辑器或在线预览，判断是内容问题还是渲染器问题。

前四步能定位绝大多数问题，剩下的基本是扩展语法不被支持。

## 二、换行、段落与强调

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 回车不换行 | 单个换行在多数解析器里等于空格 | 行尾加两个空格，或改用空行分段 |
| 段落黏在一起 | 两段之间没有空行 | 段落之间补一个空行 |
| 加粗不生效 | `**` 与文字之间有空格，或紧贴中文标点 | 去掉空格，让 `**` 紧贴文字 |
| 斜体变成加粗 | 下划线 `_` 与词内字符冲突 | 改用 `*` 包裹 |
| 星号原样显示 | 被当成列表，或符号未成对 | 转义为 `\*`，或补齐成对 |

行尾两个空格在部分编辑器里会被自动删除，这时优先用空行分段，别依赖不可见的空格。

## 三、列表、表格与代码块

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 列表断掉 | 列表项之间空行后又接了非列表行 | 保持连续，或在断开处重新起列表 |
| 嵌套失效 | 子项缩进不是 2 或 4 个空格 | 全篇统一缩进 2 或 4 空格 |
| 序号错乱 | 手动写 `1.` `2.`，中间又插了段落 | 全部写 `1.`，交给渲染器编号 |
| 表格不渲染 | 缺表头分隔行，或列数不一致 | 补上 `---` 分隔行，对齐列数 |
| 表格竖线消失 | 单元格内含未转义的 `|` | 写成 `\|` |
| 代码块吞掉后文 | 围栏只写了开头没写结尾 | 补上结尾的三个反引号 |
| 行内代码失效 | 内容首尾本身是反引号 | 改用双反引号包裹 |

序号错乱还有一层原因：不同渲染器对连续 `1.` 的处理不一致，有的按出现顺序编号，有的从起始数字延续。全写 `1.` 最稳，也最好维护。

## 四、图片、链接与导出

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 图片不显示 | 路径错、大小写不符、图片不在仓库内 | 用相对路径，核对文件名大小写 |
| 图片时好时坏 | 用了绝对路径或本机路径 | 改为相对路径，随仓库一起移动 |
| 链接 404 | 文件名或锚点写错，目标已改名 | 改成现有路径，锚点按标题重新生成 |
| 站内链接跳到文首 | 锚点缺失或被渲染器忽略 | 确认目标标题存在，锚点用标题对应形式 |
| 导出后中文乱码 | 编码不是 UTF-8 | 确认源文件为 UTF-8，导出时也选 UTF-8 |
| 导出后排版丢失 | 导出工具不支持表格、脚注等扩展 | 改用支持该语法的导出方式 |

乱码几乎都能归到编码：源文件是 GBK、导出默认 ANSI，都会出现方块或问号。先统一成 UTF-8，再谈样式。

## 五、渲染器差异怎么确认

Markdown 没有唯一标准，CommonMark 只规定核心语法，表格、任务列表、脚注、数学公式都属于扩展。确认差异的办法：

- 同一文件在两个渲染器里打开，逐段对照，找出只在一侧出错的位置。
- 把可疑片段单独抽成小文件，排除上下文干扰。
- 查渲染器的扩展开关，部分工具需要手动启用表格或脚注。
- 换一个工具再试：两边都错是内容问题，只有一边错是渲染器差异。

## 六、改内容还是换工具

| 情况 | 处理 |
| --- | --- |
| 同一语法在多数工具里都不对 | 改内容，语法写错了 |
| 只在某个工具里错，且属于扩展语法 | 换工具，或放弃该扩展 |
| 需要表格、公式，但目标平台不支持 | 换平台，或降级为图片与纯文本 |
| 导出固定乱码 | 改导出编码设置，不必换编辑器 |
| 长期依赖某个私有语法 | 换工具，私有语法会锁死内容 |

原则是内容保持通用、工具可以替换。为迁就某个工具而写非标准语法，等于把笔记绑在这个工具上，迁移时全部返工。

## 排查清单

- 块级元素前后都有空行
- 行首没有多余缩进，列表缩进全篇统一
- 正文中的 `*` `_` `|` `<` 已转义
- 代码围栏成对出现，行内代码用反引号包裹
- 表格有分隔行，各行列数一致
- 图片使用相对路径，文件名大小写正确
- 源文件与导出编码都是 UTF-8
- 同一内容在两个渲染器里预览结果一致
