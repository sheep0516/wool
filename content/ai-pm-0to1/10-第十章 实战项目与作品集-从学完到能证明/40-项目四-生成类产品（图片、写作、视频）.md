# 项目四-生成类产品（图片、写作、视频）

本项目的目标是产出可用的内容，并在成本可控的前提下稳定交付。评估重点在生成流程、参数设计、任务队列与成本。

## 4.1 范围定义

| 项目要素 | 建议 |
|---|---|
| 内容类型 | 先做单一品类，例如商品文案、海报初稿或短视频脚本 |
| 输出规格 | 固定尺寸、时长、字数范围 |
| 用户 | 内部运营或小范围外部用户 |
| 明确不做 | 长视频成片、需要高度定制风格的专业设计 |

先固定一种交付物，参数与评估才能收敛。同时做文案、图片、视频三类，会导致评估标准与流程都无法统一。

## 4.2 生成流程

```
输入（商品信息 / 需求描述 / 参考素材）
  ↓
参数补全（风格、长度、比例、语气）
  ↓
提示词组装（模板 + 结构化参数）
  ↓
生成候选（一版或多版）
  ↓
自动筛选（格式、敏感内容、明显缺陷）
  ↓
人工选择 / 修改
  ↓
导出与归档
```

关键设计：生成与筛选分离。生成阶段追求候选数量，筛选阶段用规则与模型做初筛，人工做最终选择。

## 4.3 参数设计

| 参数 | 形式 | 说明 |
|---|---|---|
| 风格 | 预设选项 | 不给空白输入，给三到五套预设 |
| 长度 | 数值或档位 | 与成本直接相关，需给默认值 |
| 比例与尺寸 | 枚举 | 固定几种尺寸，避免任意值 |
| 语气 | 枚举 | 正式、口语、活泼等 |
| 参考素材 | 上传 | 限制数量与大小 |
| 候选数量 | 档位 | 默认一版，多版需显式选择 |

参数的作用是把开放输出收窄到可交付范围。参数越多，组合爆炸越严重，成本越高；参数越少，输出可控性越差。建议核心参数控制在四到六个。

## 4.4 任务队列

生成类任务通常耗时长，必须异步化。

| 设计项 | 要求 |
|---|---|
| 提交 | 立即返回任务标识，不阻塞界面 |
| 状态 | 排队中、生成中、已完成、失败、已取消 |
| 进度 | 显示阶段，长任务显示百分比或阶段名 |
| 取消 | 支持中途取消，已消耗资源有说明 |
| 重试 | 失败可重试，重试不重复扣费 |
| 批量 | 设总量与并发上限，避免拖垮队列 |
| 结果保留 | 明确保存期限与下载方式 |

## 4.5 成本控制

| 抓手 | 做法 |
|---|---|
| 规格 | 默认中等规格，高档位需显式选择 |
| 候选 | 默认一版，多版计入额度 |
| 缓存 | 相同参数与输入复用结果 |
| 额度 | 按用户或租户设日、月上限 |
| 失败扣费 | 明确失败任务是否计入额度，避免争议 |
| 批量 | 批量任务单独计价或单独限流 |

成本与输出规格强相关：分辨率、时长、候选数量都是乘法关系。定价时应按规格分档，而不是统一单价。

## 4.6 评估方案

| 指标 | 定义 |
|---|---|
| 采纳率 | 生成结果被直接使用的比例 |
| 重度修改率 | 被大幅改写或重新生成的比例 |
| 生成成功率 | 任务成功产出可用结果的比例 |
| 平均生成时长 | 从提交到可用结果的耗时 |
| 单件成本 | 单次生成的平均成本 |
| 违规率 | 命中内容安全规则的比例 |

评估集按内容类型分层，每层包含正常需求、模糊需求、边界需求与违规诱导需求。

## 4.7 内容安全与版权

| 风险 | 处理 |
|---|---|
| 违规内容 | 输入输出双向过滤，命中拦截并说明 |
| 侵权素材 | 限制素材来源，提供合规模板，输出前检查品牌与商标 |
| 虚假信息 | 涉及事实的内容要求提供来源或标注为创意内容 |
| 深度伪造 | 涉及人像与声音的生成需显著标识，并限制用途 |
| 内容标识 | 按监管要求对生成内容加可感知标识 |

## 4.8 交付物清单

| 交付物 | 内容 |
|---|---|
| PRD | 品类、规格、参数、队列、额度、验收标准 |
| 参数规范 | 每个参数的可选值与默认值 |
| 生成流程方案 | 模板结构、候选与筛选规则 |
| 评估报告 | 采纳率、重度修改率、单件成本、违规率 |
| 成本测算 | 各规格单价、额度设计、峰值预算 |

## 4.9 常见失败

| 失败 | 原因 | 改进 |
|---|---|---|
| 用户反复重新生成 | 默认只给一版且质量不稳定 | 提供多候选、明确参数、改善提示模板 |
| 成本失控 | 高档规格被默认使用 | 默认中档，高档需显式选择并计费 |
| 排队时间过长 | 无并发限制与优先级 | 设并发上限、排队提示、分级队列 |
| 修改率居高不下 | 参数不足或风格模板单一 | 增加风格预设，提供参考素材入口 |
| 侵权投诉 | 素材来源不受控 | 素材白名单、输出前检查 |

## 4.10 自检清单

1. 是否只做单一品类，规格是否固定。
2. 参数是否有默认值，核心参数是否控制在四到六个。
3. 任务是否异步，是否支持取消与重试。
4. 失败任务是否重复扣费，规则是否明确。
5. 每种规格的单件成本是否测算过。
6. 内容安全与版权检查是否在流程内，而非事后。

## 4.11 小结

- 生成类项目应先收敛到单一品类与固定规格，参数与评估才能统一。
- 参数设计的作用是收窄输出空间，核心参数控制在四到六个。
- 任务必须异步化，状态、进度、取消、重试与批量上限都要设计。
- 成本与规格是乘法关系，应按规格分档计价并设额度。
- 内容安全与版权检查应嵌入流程，并按要求做生成内容标识。
