# 文档、表格、PPT

本节说明长文档分析、表格清洗和报告生成的做法，以及如何输出可直接交付的格式。

## 3.1 长文档分析

处理长文档时，先确认结构再提问：

1. 读取目录或章节标题，建立整体框架。
2. 按章节分段，每段保留页码与标题。
3. 先问整体问题，再问局部细节。
4. 细节问题必须回到原文，不能只用摘要回答。
5. 要求引用页码或原文片段。

常见问题：

- 扫描件识别错误，条款与数字丢失。
- 跨页表格被切断，字段错位。
- 摘要丢掉限定条件，把"在特定情况下"简化为"总是"。
- 引用只给文件名，不给页码，无法核对。

## 3.2 表格处理

表格任务分三类：

| 任务 | 做法 | 注意 |
|---|---|---|
| 数据清洗 | 去重、补缺失、统一格式、拆分列 | 不要用模型口算或推断缺失值 |
| 公式与统计 | 用表格公式或代码计算 | 模型只负责解释结果 |
| 分析与可视化 | 先计算，再让模型解读 | 要求说明统计口径 |

清洗要点：

1. 统一单位。金额、日期、百分比格式一致。
2. 处理缺失值。明确是删除、填补还是标注。
3. 去重规则。按哪个字段判断重复，保留哪一条。
4. 拆分与合并。姓名、地址、类别是否需要拆分。
5. 保留原始数据。清洗后的表单独保存，不覆盖源文件。

重要原则：精确计算交给公式或代码，不要让模型直接算。模型的输出是概率续写，不是算术引擎。

## 3.3 报告生成

从数据到报告的流程：

```
明确受众与结论 → 选图表 → 写要点 → 生成文字 → 核对数字 → 排版
```

要点：

1. 先定结论，再选材料。不要把所有数据都放进报告。
2. 图表服务于观点，不做装饰性堆砌。
3. 每个数字标注来源与口径。
4. 文字部分只解释图表，不重复罗列数据。
5. 结论与建议分开写，避免把推测写成事实。

## 3.4 PPT 生成

常见流程：

```
大纲 → 每页要点 → 讲稿 → 版式 → 导出
```

控制要点：

1. 先定页数与结构，再生成内容。
2. 每页一个观点，标题即结论。
3. 控制每页字数，避免文字溢出。
4. 统一字体、配色、页边距。
5. 图表与表格使用统一风格。
6. 生成后逐页检查排版，尤其是中文换行与项目符号。

用工具直接导出 pptx 时，需要确认：

- 模板是否保留
- 字体是否可用
- 图表是否为可编辑对象
- 备注与讲稿是否写入

## 3.5 可交付格式

| 格式 | 适用 | 注意 |
|---|---|---|
| docx | 正式文档、合同、报告 | 样式、页码、目录、批注 |
| xlsx | 数据、计算、图表 | 公式、格式、数据验证 |
| pptx | 汇报、培训 | 版式、字体、图表可编辑性 |
| pdf | 对外交付、打印 | 字体嵌入、超链接、可搜索性 |
| markdown | 内部笔记、版本管理 | 表格与图片路径 |

交付前检查：

1. 字体是否嵌入，避免对方打开时错位。
2. 页码、目录、页眉页脚是否更新。
3. 表格公式是否仍可计算。
4. 图片分辨率是否足够。
5. 链接是否可点击。
6. 是否残留批注、修订记录、隐藏信息。

## 3.6 常见失败

1. 表格结构被模型改乱，列错位。
2. 公式被替换成静态数值，无法再计算。
3. PPT 文字溢出，生成后未逐页检查。
4. 报告数字与源数据不一致。
5. 导出后字体缺失，版式错乱。
6. 文件中残留批注与修订记录，对外泄露内部意见。

## 3.7 小结

- 长文档先建结构、分段处理，细节问题回到原文并引用页码。
- 表格清洗要统一单位、处理缺失、明确去重规则，并保留原始数据。
- 精确计算交给公式或代码，模型负责解释与组织。
- 报告先定结论再选材料，每个数字标注来源与口径。
- PPT 先定结构再生成，逐页检查排版与文字溢出。
- 交付前检查字体、页码、公式、图片、链接和残留批注。
