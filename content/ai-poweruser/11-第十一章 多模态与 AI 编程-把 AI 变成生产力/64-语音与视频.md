# 语音与视频

本节说明语音转写、会议总结、配音与数字人的能力边界，以及准确率和隐私问题。

## 2.1 语音转写

影响准确率的因素：

| 因素 | 影响 |
|---|---|
| 口音与语速 | 方言、快速连读容易漏字或错字 |
| 噪声 | 背景音、多人同时说话会降低识别率 |
| 专业术语 | 缩写、产品名、人名容易识别错误 |
| 说话人数量 | 多人会议需要说话人分离，否则观点归属错位 |
| 录音质量 | 距离、设备、回声都会影响结果 |

实用做法：

1. 尽量使用安静环境与近场录音。
2. 提供术语表，提升专名识别率。
3. 要求输出时间戳与说话人标记。
4. 关键数字、人名、结论回到音频核对。
5. 长会议分段转写，避免一次处理过长。

## 2.2 会议总结

推荐流程：

```
转写 → 按议题分段 → 抽取结论、待办、分歧 → 人工复核 → 写入任务
```

需要注意：

- 口语中的条件、否定、犹豫容易被简化，结论可能被反转。
- 多人交叉讨论时，按议题分段比按发言顺序更清晰。
- 待办必须包含事项、负责人、截止时间，缺失时标注"未指定"。
- 专有名词与数字需要回到转写文本核对。

## 2.3 配音与语音合成

能力范围：

- 文本转语音，可选择音色、语速、情感。
- 多语言与多口音。
- 声音克隆，用少量样本模仿特定音色。

风险：

1. 声音克隆的授权。使用他人声音需要明确授权，模仿公众人物可能涉及人格权。
2. 平台条款。合成语音是否允许商用、是否需要标识。
3. 情感与断句。长句、专名、数字的读法容易出错，需要人工试听。
4. 隐私。录音样本包含个人信息，上传前确认存储与使用条款。

## 2.4 视频与数字人

常见用途：

- 口播视频生成、字幕、翻译。
- 数字人播报，用于课程、通知、产品介绍。
- 视频摘要，抽取关键片段与结论。

限制：

1. 长视频处理成本高，通常需要抽帧或分段。
2. 口型与表情的同步质量参差，近景容易暴露不自然。
3. 数字人形象涉及肖像权与商标权，商用需授权。
4. 生成视频的标识要求因平台和地区而异。
5. 视频理解对时间顺序、因果关系容易判断错误。

## 2.5 隐私问题

语音与视频材料通常包含大量个人信息：

- 说话人身份、声音特征
- 会议中提到的客户、金额、项目
- 画面中的面部、工牌、屏幕内容
- 地点与时间信息

处理建议：

1. 上传前确认平台条款：是否用于训练、存储多久、是否人工审核。
2. 敏感会议使用本地转写工具。
3. 对外分享的纪要删除无关的个人信息。
4. 声音克隆样本单独保管，不放入公共知识库。
5. 视频素材去除不必要的面部与屏幕内容。

## 2.6 小结

- 转写准确率受口音、噪声、术语、人数和录音质量影响。
- 会议总结按议题分段，待办要写清负责人与时间，关键内容回到音频核对。
- 配音与声音克隆涉及授权、商用条款和隐私风险。
- 视频与数字人受成本、同步质量、肖像权和标识要求限制。
- 语音视频材料含大量个人信息，敏感场景优先本地处理。
