# 图像生成与图像理解

本节说明图像理解与生成的能力、使用方法，以及商用版权与风格风险。

## 1.1 图像理解

常见能力：

| 能力 | 用途 | 局限 |
|---|---|---|
| 识图 | 描述画面、识别物体、判断场景 | 细粒度分类、空间关系容易出错 |
| OCR | 提取图片中的文字 | 小字、手写、复杂排版准确率下降 |
| 图表理解 | 读趋势、极值、对比 | 密集刻度、图例混淆时出错 |
| 界面理解 | 读截图、定位按钮、解释报错 | 分辨率低或界面复杂时定位不准 |
| 文档扫描 | 识别票据、表单、证件 | 版式歪斜、印章遮挡时字段错位 |

使用方法：

1. 提高输入质量。截图完整、清晰，必要时裁剪到关键区域。
2. 明确任务。说明看什么、输出什么格式，而不是笼统地问"这张图是什么"。
3. 要求定位。涉及数字和结论时，要求给出位置或原文。
4. 关键数字人工复核。金额、日期、编号、剂量不要直接采信。
5. 长文档分段。按页处理，避免一次输入过多导致遗漏。

## 1.2 图像生成

常见方式：

- 文生图：根据文字描述生成图片。
- 图生图：以现有图片为参考，改变风格或内容。
- 局部编辑：只修改指定区域。
- 风格迁移：把一张图的风格应用到另一张。

提示词通常包含六类信息：

```
主体：画面中有什么，数量、动作、关系
场景：地点、环境、背景
风格：写实、插画、摄影、扁平、复古
构图：视角、景别、主体位置、留白
光线：时间、方向、色温、对比
画幅：横竖比例、用途
```

需要控制时，可以补充负面要求，例如不要文字、不要多余手指、不要特定品牌标识。

## 1.3 常见问题

1. 图中文字渲染错误。生成图片中的文字常常拼写错误或变形，需要后期排版。
2. 细节不一致。多个人物、多个物体时，数量、手指、配件容易出错。
3. 风格漂移。同一组提示词，多次生成风格差异较大。
4. 版权与商标。生成的画面可能包含受保护的标识、角色或建筑。
5. 人物肖像。使用真实人物照片或生成相似形象，涉及肖像权。

## 1.4 商用版权与风格风险

使用生成图片前确认：

| 项目 | 需要确认 |
|---|---|
| 平台条款 | 生成内容是否允许商用，归属如何约定 |
| 训练数据 | 是否使用受版权保护的材料，平台是否提供赔偿条款 |
| 商标与角色 | 画面中是否出现品牌标识、动漫角色、名人形象 |
| 肖像权 | 是否使用真实人物照片，是否生成可识别的人物 |
| 风格模仿 | 是否刻意模仿在世艺术家或特定品牌视觉 |
| 标识义务 | 部分地区或平台要求标注"AI 生成" |

无法确认时，不要直接商用。可以改为自制素材、购买授权素材，或把生成图作为草图，再由人重绘。

## 1.5 使用建议

1. 生成图作为初稿，文字和关键元素后期处理。
2. 保留提示词、生成记录和修改过程，便于追溯。
3. 不直接使用含品牌、名人、特定角色的画面。
4. 对外发布前检查平台条款与标识要求。
5. 重要素材准备替代方案，避免单一生成结果无法使用。

## 1.6 小结

- 图像理解包括识图、OCR、图表理解、界面理解和文档扫描，细节与空间关系容易出错。
- 图像生成包括文生图、图生图、局部编辑和风格迁移，提示词按主体、场景、风格、构图、光线、画幅组织。
- 常见问题是文字渲染错误、细节不一致、风格漂移和版权风险。
- 商用前要确认平台条款、训练数据、商标角色、肖像权和标识义务。
- 生成图应作为初稿，文字与关键元素后期处理，并保留生成记录。
