# 大模型到底在做什么

本节说明大模型生成文本的机制，以及"看起来懂"与"真正理解"之间的差距。理解这两点，后面的幻觉、提示词、校验等内容才有落脚点。

## 2.1 生成的基本单位是 token

模型不直接处理"字"或"词"，而是处理 token。token 是文本被切分后的最小单位，可能是一个词、一个子词或一个字符。中文通常 1 个汉字对应 1 个 token 左右，英文一个单词可能被拆成多个 token。

两个直接后果：

- 计费和上下文长度按 token 计算，而不是按字数。
- 模型看到的是 token 序列，对字符级细节（如精确字数、罕见拼写）并不敏感。

上下文窗口指模型一次能看到的 token 上限。超出部分会被截断或压缩，这也是长文档处理必须分段的原因之一。

## 2.2 核心机制：预测下一个 token

给定一段上文，模型计算词表中每个 token 作为下一个 token 的概率，然后从中选一个，拼接到上文后面，再重复这一过程。

用公式表达就是：

```
P(t_n | t_1, t_2, ..., t_{n-1})
```

整段回答由一个个 token 逐步生成，这种方式称为自回归生成。

由此可以推出几个常被忽略的特性：

1. 模型不是先想好整段再输出，而是边生成边决定下一步。开头一旦偏离，后面的内容会沿着已生成的上文继续走，错误会累积。
2. 生成长文本时，早期内容会成为后续内容的"事实前提"，因此长文容易出现前后矛盾或主题漂移。
3. 输出是逐 token 采样得到的，同一输入不保证同一输出，具体原因见第4节。

## 2.3 训练分两个阶段

### 预训练

在海量文本上反复做"预测下一个 token"。通过这一目标，模型学到了：

- 语法与搭配习惯
- 事实之间的共现关系
- 常见论述结构与写作风格
- 部分推理模式的表层形式

预训练得到的是统计规律，不是结构化的知识库。模型没有为每条事实建立索引，知识分布在参数中，无法逐条溯源。

### 对齐（后训练）

预训练模型只会"续写"，不一定会"回答问题"。对齐阶段用指令数据和人类偏好数据做微调，使模型：

- 按指令格式作答
- 优先给出有用、无害的回答
- 拒绝明显有害的请求
- 在不确定时给出更保守的表述

对齐改变的是行为偏好和表达方式，不会补充预训练阶段没有的知识，也不会消除事实性错误。

### 推理

使用时只做前向计算与采样，不更新参数。模型不会因为一次对话"学会"新知识，对话中的信息只存在于当前上下文里。

## 2.4 为什么它"看起来懂"

在常见话题上，模型的表现接近理解，原因有三点：

1. 语言本身承载了大量世界知识。学会预测文本，就间接学到了"什么和什么通常一起出现"。
2. 训练数据覆盖了大量解释、论证和问答，模型学到了这些模式的表面结构。
3. 上下文本身提供了线索。模型可以在上下文内完成类比、归纳和格式模仿，这被称为上下文学习。

但这种"懂"有明确边界：

| 能力 | 表现 | 局限 |
|---|---|---|
| 语言组织 | 强，接近人类写作 | 流畅不代表正确 |
| 常见事实 | 多数正确 | 长尾、时效性内容易错 |
| 模式识别 | 能识别常见题型与结构 | 分布外任务迅速退化 |
| 因果与反事实 | 能复述常见因果说法 | 缺少稳定因果模型，换条件易错 |
| 不确定性校准 | 能表达"可能" | 常过度自信，不知道自己不知道 |
| 自我解释 | 能说明"为什么这么答" | 解释多为事后生成，不等于真实计算过程 |

判断"是否真正理解"，通常看三项：能否泛化到训练分布之外、能否一致地进行反事实推理、能否准确校准自己的不确定性。当前模型在这三项上都不稳定。

对使用者而言，只需要记住两条操作结论：

- 流畅不等于正确。
- 合理不等于有据。

## 2.5 这些机制对使用方式的影响

1. 输入决定输出。上下文、示例、约束条件都会改变概率分布，提示词的作用不是"咒语"，而是缩小解空间。
2. 输出应按草稿对待。事实、数字、引用、结论都需要外部校验。
3. 长任务要分段。误差会随 token 累积，分段执行并在每段校验，比一次性生成更可靠。
4. 模型不会记住对话之外的内容。需要长期知识时，要用知识库或文件，而不是依赖模型记忆。

## 2.6 小结

- 大模型的基本动作是预测下一个 token，整段输出由逐步采样拼接而成。
- 预训练学到统计规律，对齐学到行为偏好；两者都不保证事实正确。
- 模型在常见语言模式上表现接近理解，但缺少稳定的因果模型与不确定性校准。
- 流畅性与事实性、合理性与有据性，是两组相互独立的判断。
- 使用上的直接推论：控制输入、校验输出、长任务分段、长期知识外置。
