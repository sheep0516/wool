# Prompt 的四要素

本节说明一个可用的 Prompt 应包含哪四类信息，以及为什么"说清楚"比"说得多"更重要。

## 1.1 四要素

| 要素 | 回答的问题 | 常见内容 |
|---|---|---|
| 角色 | 以什么身份、什么视角回答 | 领域、经验层级、面向的读者 |
| 任务 | 具体要做什么 | 动作、范围、成功标准 |
| 上下文 | 在什么背景下做 | 背景信息、材料、受众、限制条件 |
| 输出格式 | 结果长什么样 | 结构、长度、语言、字段、示例 |

四要素不必每次都写全，但缺哪一项，模型就会在那一项上自行决定，结果通常与预期有偏差。

## 1.2 角色

角色影响模型选择的词汇、默认知识层级和论述角度。

有效写法：

```
你是一位给非技术管理者写说明的技术顾问，避免术语堆砌，必要时用类比解释。
```

无效写法：

```
你是一位世界顶级、无所不知的专家。
```

后者的信息量接近零，不会改变输出分布。角色要与任务匹配：给小白解释、给专家评审、给客户写邮件，三种场景的默认表达方式不同。

角色也有边界。它不能凭空增加模型没有的知识，也不能保证专业准确性。涉及专业判断时，角色设定只影响表达，不影响事实。

## 1.3 任务

任务部分要写清三件事：

1. 动作：总结、改写、分类、抽取、评审、生成。
2. 对象：处理哪份材料、哪个范围。
3. 标准：什么算完成，什么算不合格。

示例：

```
把下面这份会议记录整理成三部分：已达成结论、待定事项、下一步行动。
每部分不超过 5 条，行动项需标注负责人和截止时间；记录中没有的信息写"未提及"。
```

含糊写法如"帮我看看这份会议记录"，会让模型自行决定输出结构和详略。

## 1.4 上下文

上下文包括：

- 这份材料是什么、给谁看、用于什么场合。
- 已知的背景、前提、术语含义。
- 不能改变的事实、必须保留的信息。
- 篇幅、语气、合规等限制。

上下文的作用是缩小解空间。信息越具体，模型越不容易朝无关方向发挥。但上下文不是越多越好，与任务无关的材料会稀释注意力，甚至引入冲突信息。

## 1.5 输出格式

输出格式决定结果能否直接使用。需要写明：

- 结构：段落、列表、表格、JSON、评分卡。
- 长度：字数、条数、页数上限。
- 语言与语气：中文、英文、正式、口语。
- 字段与单位：日期格式、金额单位、枚举值。
- 是否允许附加解释。

示例：

```
输出为 Markdown 表格，列为：问题、原文位置、风险等级、修改建议。
不要输出表格之外的说明文字。
```

不写格式时，模型会给出它认为合适的结构，往往需要二次整理。

## 1.6 为什么"说清楚"比"说得多"重要

### 注意力会被稀释

上下文越长，关键指令越容易被淹没。模型可能抓住最后几句，或抓住最显眼但与任务无关的内容。

### 指令可能相互冲突

"尽量详细"与"控制在 200 字"、"保持专业"与"让小白看懂"，同时出现时模型只能自行取舍，结果不稳定。

### 冗余描述不增加信息

"非常重要、请务必认真、尽可能完美"这类强调，对输出分布影响很小。有效的做法是给出可检验的标准，例如"每条结论必须对应原文中的一句话"。

### 隐含要求不会被自动理解

"写得好一点"在不同人那里含义不同。需要拆成可执行的条件：目标读者、篇幅、结构、必须包含的要点、禁止出现的内容。

## 1.7 四要素检查表

写完 Prompt 后逐项检查：

- 角色是否与任务匹配，是否具体到能影响表达
- 任务的动作、对象、标准是否明确
- 上下文是否包含必要背景，是否混入无关材料
- 输出格式是否可直接使用
- 是否存在相互冲突的指令
- 是否有无法检验的形容词

## 1.8 改写示例

改写前：

```
帮我写一篇关于 AI 对教育影响的文章，要写得好一点，专业一点，不要太长。
```

改写后：

```
角色：面向中学教师的教育技术研究者。
任务：写一篇说明 AI 在课堂教学中的实际用途与限制的文章。
上下文：读者是没有技术背景的一线教师；不讨论政策与商业；只谈课堂场景。
约束：1200 字以内；分四部分：可用场景、限制、教师需要做的准备、常见误区；每部分给出一个具体例子。
输出格式：Markdown，四个二级标题，不要开场总结，不要结尾口号。
```

改写后的版本并没有更长太多，但每一项要求都可以检验。

## 1.9 小结

- Prompt 的四要素是角色、任务、上下文、输出格式。
- 角色影响表达视角，不增加知识；空泛的角色设定没有作用。
- 任务要写清动作、对象和完成标准。
- 上下文用于缩小解空间，无关材料会稀释注意力。
- 输出格式决定结果能否直接使用。
- 有效 Prompt 的标准是"可检验"，而不是"字数多"或"语气强"。
