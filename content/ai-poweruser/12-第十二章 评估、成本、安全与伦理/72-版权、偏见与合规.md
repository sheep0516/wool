# 版权、偏见与合规

本节说明生成内容的版权风险、偏见的识别与复核，以及对外发布前的人工责任。

## 4.1 版权风险

| 风险 | 说明 |
|---|---|
| 训练数据 | 模型训练使用了大量受版权保护的材料，生成结果可能与现有作品相似 |
| 风格模仿 | 刻意模仿在世艺术家或特定品牌的视觉风格 |
| 素材使用 | 上传他人图片、文档作为参考，可能超出授权范围 |
| 平台条款 | 生成内容的商用许可、归属与赔偿条款各不相同 |
| 标识义务 | 部分地区或平台要求标注"AI 生成" |
| 输出相似 | 生成的文字、代码可能与已有作品高度相似 |

需要区分三件事：

1. 生成内容是否受版权保护。不同司法辖区的规定不同。
2. 生成过程是否侵犯他人权利。训练数据与参考素材都可能涉及。
3. 使用方式是否合规。商用、公开发布、二次修改的规则不同。

无法确认时，不要直接商用。可以改用自制素材、购买授权，或把生成内容作为草图再重绘。

## 4.2 偏见

偏见的来源：

- 训练数据中的历史偏见与分布失衡。
- 提示词中的隐含假设。
- 模型对齐时偏向某类表达或立场。
- 检索资料本身带有倾向。

常见表现：

- 职业、性别、地域的刻板印象。
- 对某些群体的描述过于单一。
- 在争议话题上只呈现一方观点。
- 推荐结果集中于主流选项，忽略少数情况。

识别方法：

1. 换一组人群描述，看结论是否发生不合理变化。
2. 要求模型列出反例与不同立场。
3. 检查样本是否只来自单一来源。
4. 对涉及人群的判断，人工复核。

## 4.3 合规

常见要求：

| 领域 | 关注点 |
|---|---|
| 个人信息保护 | 收集、使用、存储、跨境传输 |
| 广告与宣传 | 禁止虚假宣传、绝对化用语 |
| 行业规定 | 医疗、金融、教育等有专门要求 |
| 平台规则 | 内容标识、禁止类别、发布频率 |
| 劳动与人事 | 自动化决策的告知与申诉 |

合规责任由发布者承担，不因内容由 AI 生成而转移。

## 4.4 对外发布前检查

1. 事实与数字有来源。
2. 引用可打开原文。
3. 无受版权保护的素材被直接使用。
4. 无对特定群体的刻板描述。
5. 无绝对化、承诺性、误导性表述。
6. 已按平台或地区要求标注 AI 生成。
7. 无未脱敏的个人信息。
8. 已获得必要的授权。

## 4.5 人工责任

AI 可以生成内容，但不能承担责任。对外发布前，需要有人对以下事项负责：

- 内容是否真实、准确。
- 是否侵犯他人权利。
- 是否符合行业与平台规定。
- 是否会造成误导或伤害。

这个责任人必须是具体的人，而不是"模型"或"系统"。

## 4.6 小结

- 版权风险涉及训练数据、风格模仿、参考素材、平台条款、标识义务和输出相似。
- 生成内容是否受保护、是否侵权、使用是否合规，是三个不同问题。
- 偏见来自数据、提示词、对齐和检索资料，表现为刻板印象与单一视角。
- 合规涉及个人信息、广告宣传、行业规定、平台规则和自动化决策。
- 发布前检查事实、引用、素材、偏见、表述、标识、隐私和授权。
- 合规与内容责任由发布者承担，不因由 AI 生成而转移。
