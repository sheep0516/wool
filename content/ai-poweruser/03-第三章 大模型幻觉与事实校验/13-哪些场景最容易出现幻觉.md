# 哪些场景最容易出现幻觉

本节列出高风险信息类型、对应的典型表现，以及按风险分级的核查清单。

## 2.1 高风险信息类型

| 类型 | 典型表现 | 原因 |
|---|---|---|
| 人名与职务 | 编造履历、错误任职、张冠李戴 | 同名实体多，长尾人物资料少 |
| 数字与统计 | 金额、比例、排名、增长率偏差 | 需要精确匹配，模型倾向生成"合理"数值 |
| 日期与时间 | 事件年份、政策生效日、版本发布时间错误 | 训练数据过期，时间关系混淆 |
| 法条与政策 | 条款编号、适用范围、处罚标准错误 | 法规更新频繁，条文细节多 |
| 论文与书籍引用 | 编造标题、作者、期刊、DOI、页码 | 引用格式有强模式，内容无需真实存在 |
| 产品参数与价格 | 规格、兼容性、售价、套餐内容错误 | 版本迭代快，信息分散 |
| 实时信息 | 股价、天气、赛事、库存、汇率 | 训练截止后无数据 |
| 专业细节 | 医学剂量、药物相互作用、工程参数 | 容错低，长尾知识缺失 |
| 代码与接口 | 不存在的函数、过时的参数、错误的库版本 | API 变化快，示例代码可能来自旧版本 |
| 地址与联系方式 | 编造电话、邮箱、办公地点 | 模式化字段容易被"合理填充" |

共同特征是：需要精确匹配、更新频繁、属于长尾知识，或用户本人难以验证。

## 2.2 什么情况下幻觉更严重

1. 问题越具体。问"某公司 2024 年第三季度毛利率是多少"比问"毛利率是什么"更容易出错。
2. 话题越冷门。小众人物、地方政策、细分行业数据，训练语料覆盖不足。
3. 要求越精确。要求给出条款编号、页码、DOI 时，模型会用格式正确的假信息填补。
4. 提问带预设。"是不是因为 A 所以 B"这类问法会诱导模型顺着前提回答。
5. 多轮对话累积。早期的一个错误结论会被后续轮次当作事实继续展开。
6. 长文档摘要。细节在压缩过程中丢失或被替换。
7. 翻译与专名。人名、机构名、术语在跨语言转换时容易失真。
8. 时间敏感。涉及"最新""当前""今年"的问题，模型缺少实时依据。

## 2.3 高风险场景清单

按使用场景划分，以下情况需要额外核查：

- 对外发布的文章、报告、方案中的事实与数据。
- 涉及金额、合同条款、报价、预算的内容。
- 法律、医疗、税务、安全操作相关的内容。
- 学术写作中的文献引用、数据来源、研究方法描述。
- 产品文档中的参数、兼容性、版本说明。
- 对外沟通中的客户名称、职务、联系方式。
- 任何带"最新""第一""唯一""官方规定"等绝对化表述的句子。
- 自动化流程中直接对外发送或提交的内容。

## 2.4 风险分级

| 等级 | 特征 | 核查方式 |
|---|---|---|
| A 必须核实 | 数字、法条、引用、医疗法律内容、对外发布 | 找到原始来源，逐项核对 |
| B 应当抽检 | 常规事实、行业常识、产品描述 | 抽查关键结论与数字 |
| C 可接受 | 观点、文风、头脑风暴、内部草稿 | 无需逐条核实，标注为草稿 |

分级依据是错误代价与可验证性，而不是内容看起来是否可信。

## 2.5 识别信号

以下表述出现时，应提高警惕：

- "根据某研究""数据显示""据统计"，但没有给出可核对来源。
- 给出精确到小数点的数字，却没有说明统计口径。
- 引用格式完整，但无法检索到原文。
- 语气确定，且没有任何限定词。
- 内容与用户提问中的预设高度一致。
- 同一段材料中，前后数字或时间不一致。

## 2.6 小结

- 高风险信息集中在人名、数字、日期、法条、引用、产品参数、实时信息和专业细节。
- 问题越具体、话题越冷门、要求越精确，幻觉概率越高。
- 对外发布、金额、法律医疗、学术引用、自动化执行属于必须核实的场景。
- 按错误代价与可验证性分三级，而不是按内容可信度分。
- 出现无来源的精确数字、完整引用、绝对化表述时，应优先核查。
