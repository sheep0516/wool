# 搭建单 Agent

本节给出四种常见单 Agent 的设计要点：个人助理、学习教练、内容创作、资料研究。

## 3.1 通用搭建顺序

无论哪种 Agent，都按同一顺序：

1. 写需求：用户、任务、输入输出、成功标准、边界。
2. 写指令：角色、步骤、输出格式、拒答规则。
3. 配知识库：只放相关文档，结构清晰，可引用。
4. 配工具：最小集合，读写分离。
5. 设记忆：只存必要信息，可查看与删除。
6. 测试：用真实问题，包括无答案与边界样本。
7. 发布：确认渠道、权限与反馈入口。

## 3.2 个人助理 Agent

目标：处理日常事务性任务，例如整理待办、起草消息、查询资料。

输入：自然语言请求、日程、邮件摘要、待办清单。
组件：

- 指令：明确可处理的 task 类型，超出范围时说明。
- 知识库：个人常用资料、模板、联系人信息（脱敏）。
- 工具：日历读写、邮件草稿、待办创建；写操作需确认。
- 记忆：常用偏好，例如称呼、格式习惯。

输出：草稿、清单、提醒建议。
失败点：把草稿直接发送、误改日程、把敏感信息写入长期记忆。

## 3.3 学习教练 Agent

目标：按固定节奏讲解概念、出题、检查理解。

输入：主题、已有基础、可用材料。
组件：

- 指令：讲解深度、例子类型、提问方式、评分标准。
- 知识库：教材、课程讲义、错题记录。
- 工具：可选的搜索与计算工具。
- 记忆：已学主题、薄弱点、历史错题。

输出：讲解、练习、反馈。
失败点：只给定义不给边界、出题超出范围、把错误答案判为正确、跳过基础直接讲进阶。

## 3.4 内容创作 Agent

目标：从选题到初稿，产出可编辑的内容。

输入：主题、受众、平台、篇幅、风格要求。
组件：

- 指令：结构模板、语气、禁止项、事实要求。
- 知识库：品牌规范、历史稿件、素材库。
- 工具：搜索、图片生成、数据查询。
- 记忆：常用风格、已用过的选题。

输出：选题清单、提纲、初稿、标题备选。
失败点：编造事实与数据、风格漂移、重复旧选题、违反平台规则。

内容创作 Agent 不应直接发布。发布环节必须保留人工审核。

## 3.5 资料研究 Agent

目标：围绕一个问题收集、整理、对比资料，形成带来源的结论。

输入：研究问题、范围、时间限制、来源要求。
组件：

- 指令：检索策略、来源优先级、引用格式、冲突处理。
- 知识库：已有资料、历史研究。
- 工具：搜索、网页读取、文档解析。
- 记忆：已确认的事实、待核实项。

输出：资料清单、对比表、结论与来源、未解决问题。
失败点：引用不存在、把二手转述当原始来源、忽略反例、结论超出材料范围。

## 3.6 四类 Agent 的共同结构

| 部分 | 共同要求 |
|---|---|
| 输入 | 明确需要用户提供什么，缺失时追问 |
| 处理 | 步骤可描述，每步有检查点 |
| 输出 | 格式固定，可直接使用 |
| 边界 | 明确不做什么，什么情况拒答 |
| 失败 | 说明原因，给出可执行下一步 |

差别主要在知识库内容、工具集合和输出格式，而不是整体架构。

## 3.7 小结

- 单 Agent 的搭建顺序是需求、指令、知识库、工具、记忆、测试、发布。
- 个人助理侧重事务处理与写操作确认，学习教练侧重讲解与反馈，内容创作侧重结构与风格，资料研究侧重来源与引用。
- 四类 Agent 的共同结构是输入、处理、输出、边界和失败处理。
- 内容创作不应直接发布，资料研究必须给出可核对来源。
- 失败点集中在越权操作、事实编造、范围失控和记忆错误。
