# 输出审校与二次加工

本节说明交付前的四类审校、审校顺序，以及如何建立自己的交付检查表。

## 5.1 四类审校

| 类型 | 检查什么 | 常见问题 |
|---|---|---|
| 事实审 | 数字、日期、人名、引用、结论 | 无来源、来源过期、引用不存在 |
| 逻辑审 | 前提、推理、因果、前后一致 | 论证跳跃、循环论证、自相矛盾 |
| 风格审 | 受众匹配、语气、术语、冗余 | 术语不统一、语气不符、重复表达 |
| 格式审 | 结构、字段、长度、单位 | 缺字段、超字数、单位混用 |

四类问题中，事实错误优先级最高，因为它无法通过表达修饰挽回。格式问题最容易被程序发现，应尽量前置。

## 5.2 审校顺序

建议顺序：事实 → 逻辑 → 风格 → 格式。

原因：

1. 事实错误会改变结论，先改事实，后续审校才有意义。
2. 逻辑问题常由事实错误引起，事实核对后可能自然消失。
3. 风格与格式调整属于表达层，放在最后，避免反复修改。
4. 格式可以用程序批量检查，适合放在流程末端做兜底。

顺序不是绝对的。批量结构化输出可以先做格式校验，快速筛掉不合格项，再进入内容审校。

## 5.3 事实审的做法

1. 列出所有需要核实的项：数字、日期、专名、引用、绝对化表述。
2. 逐项找原始来源，记录链接与访问日期。
3. 引用必须能打开原文，搜不到按不存在处理。
4. 数字要确认统计口径与单位。
5. 无法核实的内容，删除或明确标注。

事实审不要求核查每一句话。观点、文风、结构不需要核实，除非其中夹带了事实。

## 5.4 逻辑审的做法

检查以下方面：

- 前提是否成立，是否被当作已知事实。
- 推理是否有跳跃，中间步骤是否缺失。
- 因果是否被倒置，相关是否被写成因果。
- 是否存在以偏概全、样本不足。
- 前后结论是否矛盾，不同章节是否使用同一标准。
- 是否存在循环论证：用结论证明前提。

一个实用方法：把每一段的结论单独摘出来，按顺序排列，看它们是否能连成一条一致的论证链。连不上或互相冲突的地方，就是逻辑问题所在。

## 5.5 风格审的做法

1. 对照目标受众。给管理层看与给执行层看，详略和术语不同。
2. 检查术语一致性。同一概念是否使用了多个说法。
3. 删冗余。重复表达、无信息量的过渡句、空泛形容。
4. 检查语气。是否存在过度确定、过度承诺、煽动性表达。
5. 检查限定条件。把"总是""一定""所有"改为有条件表述，除非确有依据。

## 5.6 格式审的做法

1. 结构是否符合要求：章节、层级、顺序。
2. 字段是否齐全：表格列、JSON 键。
3. 长度是否超限：字数、条数、单元格长度。
4. 单位与格式是否统一：日期、金额、百分比。
5. 链接与引用是否可点击。
6. 是否存在解析会失败的字符，例如表格单元格内换行。

格式审尽量用程序完成，人工只处理程序无法判断的部分。

## 5.7 二次加工

审校之后通常还需要一轮加工：

- 删掉不影响主线的细节，降低阅读负担。
- 把长句拆开，把并列关系改成列表。
- 补充必要的背景与定义，避免读者缺少前提。
- 把结论前置，把论证过程放在后面。
- 统一术语与格式。
- 为关键结论补上来源。

二次加工的原则是不改变事实与结构，只调整表达。若加工过程中发现事实问题，应回到事实审，而不是用措辞掩盖。

## 5.8 让 AI 自审的写法与局限

可以要求模型按清单自检：

```
请按以下清单检查你刚才的输出，逐项说明是否通过，并列出需要修改的地方：
1. 每个数字是否有来源
2. 是否存在前后矛盾
3. 是否遗漏了限定条件
4. 格式是否符合要求
5. 是否有无法核实的绝对化表述
不要直接重写，先给出检查结果。
```

局限：

- 模型可能漏掉自己的错误，尤其是事实错误。
- 模型可能把错误项标为通过。
- 自审不能替代外部来源核对。

因此，自审适合作为第一道过滤，不能作为最终校验。

## 5.9 交付检查表

| 序号 | 检查项 | 通过标准 |
|---|---|---|
| 1 | 数字与日期 | 有来源，口径与单位一致 |
| 2 | 引用 | 能打开原文，作者与标题匹配 |
| 3 | 结论 | 有依据，无循环论证 |
| 4 | 前后一致性 | 无矛盾，术语统一 |
| 5 | 限定条件 | 绝对化表述已改为有条件表述 |
| 6 | 受众匹配 | 详略与术语符合读者背景 |
| 7 | 格式 | 结构、字段、长度符合要求 |
| 8 | 敏感信息 | 无未脱敏的个人信息与客户数据 |
| 9 | 授权 | 无未经确认的承诺与对外表态 |
| 10 | 不确定项 | 已标注，未伪装成确定结论 |

检查表应根据自己的任务类型调整，不必照搬。

## 5.10 小结

- 审校分四类：事实、逻辑、风格、格式。
- 建议顺序是事实优先，格式最后；批量任务可先用程序做格式兜底。
- 事实审靠原始来源，逻辑审靠结论链，风格审靠受众与术语，格式审靠程序。
- 二次加工只调整表达，不改变事实与结构。
- 模型自审只能作为第一道过滤，不能替代外部核对。
- 交付检查表的作用是把容易遗漏的项固定下来。
