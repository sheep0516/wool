# 长文档、会议、课程的处理方法

本节说明超出上下文长度的材料如何分段处理，以及如何建立可检索的索引。

## 3.1 为什么不能一次塞满

把整份长文档、整场会议记录或整门课程一次性投入上下文，会遇到四个问题：

1. 超出窗口。超出部分被截断，模型看不到。
2. 中间遗忘。即使没有超限，夹在长上下文中间的内容也容易被忽略。
3. 细节丢失。压缩成摘要时，限定条件、数字、例外条款最容易消失。
4. 成本上升。输入 token 随长度线性增长，长材料单次调用费用明显增加。

因此，长材料的处理原则是分段、分层、可定位，而不是一次投喂。

## 3.2 分段总结

按材料自身的结构切分，而不是按字数机械切分：

- 文档：按章节、标题、页码切分。
- 会议：按议题或时间段切分。
- 课程：按讲次、章节或知识点切分。

每段的处理方式：

```
这是第 X 部分（第 X 页至第 X 页）。
请输出：
1. 本部分的核心内容（不超过 5 条）
2. 出现的关键数字、日期、人名
3. 与其他部分可能相关的衔接点
4. 本部分未说明、需要后文补充的问题
```

要求保留页码或时间戳，是为了后续能回到原文核对。

## 3.3 建立索引

分段之后，需要一份索引，否则摘要堆积在一起仍然无法定位。索引条目建议包含：

| 字段 | 内容 |
|---|---|
| 位置 | 页码、章节号、时间戳 |
| 标题 | 该部分的主标题 |
| 一句话摘要 | 这部分讲了什么 |
| 关键实体 | 人名、机构、产品、数字 |
| 关联问题 | 与哪些部分相关 |
| 可信度备注 | 是否有缺失页、扫描不清等 |

索引的价值在于：后续提问时，先通过索引定位到相关段落，再只把那几段送入模型，而不是重新加载全文。

## 3.4 分层提问

按"整体—部分—细节"三层提问：

1. 整体层：这份材料的主题、结构、主要结论是什么。
2. 部分层：第 3 章论证了什么，用了哪些证据。
3. 细节层：某一句、某个数字、某个条款的具体含义。

不同层使用不同的材料范围。整体层可以只给目录和摘要；细节层必须给原文片段。把三层混在一次提问里，模型容易用摘要回答细节，产生"看似回答了但无法核对"的结果。

## 3.5 会议记录的处理

推荐流程：

1. 转写。先得到带时间戳的文本，保留说话人标记。
2. 分段。按议题切分，而不是按发言顺序平铺。
3. 抽取。每个议题输出：讨论要点、已达成的结论、分歧、待办。
4. 待办要素。事项、负责人、截止时间、依赖条件；缺失项标注"未指定"。
5. 核对。专有名词、数字、人名回到转写文本确认。

常见问题：

- 说话人识别错误，导致观点归属错位。
- 口语中的否定和条件被简化，结论被反转。
- 多个议题交叉讨论，分段时把内容放错议题。
- 待办没有负责人，被模型自行分配。

## 3.6 课程与讲义的处理

推荐流程：

1. 先读目录或大纲，建立整体结构。
2. 每讲输出概念卡：定义、作用、前提、例子、常见误解。
3. 标记前后依赖，形成知识顺序。
4. 生成问题清单，用于自测。
5. 用复述检验：合上材料，用自己的话讲一遍，再对照原文找差距。

课程材料的重点不是摘要，而是概念之间的关系和适用边界。只做摘要，容易得到一堆互不连接的要点。

## 3.7 长文问答的做法

回答长文问题时，按以下顺序：

1. 先用索引或检索定位相关段落。
2. 只把相关段落送入模型，要求基于该段落回答。
3. 要求给出页码或原文片段。
4. 对跨段落的结论，分别核对每段的依据。
5. 找不到依据时，明确写"材料未提及"，不要用摘要推测。

## 3.8 常见失败情况

1. 摘要丢失限定条件，把"在特定条件下"简化为"总是"。
2. 跨段引用错误，把甲段的结论记到乙段。
3. 合并多段时重复内容未去重。
4. 会议时间戳错位，待办对应到错误的议题。
5. 索引缺少页码，后续无法回到原文。
6. 分段边界切在论证中间，导致每段都不完整。

## 3.9 小结

- 长材料不能一次塞满，问题是超限、中间遗忘、细节丢失和成本上升。
- 按材料结构分段，每段保留位置标识与关键实体。
- 建立索引，包含位置、摘要、实体、关联问题和可信度备注。
- 提问分整体、部分、细节三层，细节层必须回到原文。
- 会议重点是议题、结论、分歧、待办；课程重点是概念关系与边界。
- 长文问答先定位再回答，并要求给出可核对的位置。
